Lab 04 Function Calling Mechanisms
Problem Statement:
This lab explores basic function invocation, parameter passing, and control flow between calling and called functions in C++.
Approach:
The program demonstrates modular programming by defining separate functions for display, addition, and 
multiplication, which are invoked from the main function.
Complexity Analysis:
 * Time Complexity: O(1), as operations involve basic arithmetic and sequential execution.
 * Space Complexity: O(1), utilizing fixed memory for local variables.
Sample I/O:
Input: Enter two numbers 4 6.
Output: Sum= 10, Addition= 10, Multiplication= 24.
Learning Outcomes:
I understood the mechanics of function calls, variable scope, basic control transfer, and the importance of code modularity.
