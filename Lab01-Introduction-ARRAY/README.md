Lab 01 Array Operations
Problem Statement:
This lab implements fundamental array operations including traversal, insertion, finding
minimum and maximum values, and reversing the array elements.
Approach:
The program utilizes class methods to manipulate a fixed-size array, updating the logical size dynamically during insertions.
Complexity Analysis:
 * Time Complexity: O(N) for traversal, finding min/max, and reversing; O(N) for insertion due to element shifting.
 * Space Complexity: O(MAX) for the static array allocation.
Sample I/O:
Input: Array size 5, Elements 5 6, Insert position 1 data 1.
Output: Array elements 5 6, Minimum 5, Maximum 6.
Learning Outcomes:
I observed the impact of uninitialized variables and understood linear search efficiency and memory shifts.
